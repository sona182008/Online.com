# Renu Store Pro — Redesigned

A modern responsive redesign of the uploaded Renu Store Pro project using only HTML5, CSS3 and vanilla JavaScript.

## Included
- Modern responsive homepage
- Products page with search/filter/sort
- Search page with history and suggestions
- LocalStorage cart with quantity controls and coupons
- Checkout validation and local order record
- Wishlist
- Login/signup/Forgot Password UI
- Firebase authentication bridge (credentials remain placeholders)
- Contact and support/information pages
- Responsive mobile navigation
- Accessible focus states and reduced-motion support
- Local image assets preserved/reused from the uploaded project

## Run
Open `index.html` directly in a browser.

## Firebase
The authentication code is preserved as a Firebase integration. To enable real login/signup/Google authentication, replace the placeholder values in `auth.js` with the Web App configuration from your Firebase project.

No framework, build step, Node.js server, PHP, React, Vue, Angular, Bootstrap, Tailwind or jQuery is required.
